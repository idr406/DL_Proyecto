# DL_Proyecto
# DULCERIA LUPITA

La Dulceria Lupita ubicada en Acatlan de Osorio Puebla, atraviesa un momento complicado a  por falta de control, orden interno y estructura organizacional esto debido a que no cuentan  con un control digital de entradas/salidas, desconexión con SICAR  y el área de ventas, lo que origina que los clientes demoren en el proceso de la compra de  productos, extravío de productos o productos caducos derivado de esta situación surge la idea de diseñar, crear e implementar estrategias de mercado con el fin de aumentar las ventas  tanto en piso como en el comercio electrónico, agilizando procesos de compra/venta, fortaleciendo su relación y atención con el cliente final 

## Comenzando 🚀

Estas instrucciones te permitirán obtener una copia del proyecto en funcionamiento en tu máquina local para propósitos de desarrollo y pruebas.

### Pre-requisitos 📋

Para que el sistema funcione correctamente se debe cumplir con las siguientes especificaciones técnicas:

* **Servidor Web:** Apache con soporte para redirección `.htaccess`.
* **Entorno de Ejecución:** Servidor con soporte para **Node.js** (Versión 18.x LTS o superior) o un Hosting compatible con aplicaciones JavaScript modernas.
* **Base de Datos:** Servidor **MySQL**.
* **Seguridad:** Certificado **SSL (HTTPS)** activo y configurado en el dominio/subdominio de la dulcería.
* **Administrador de Archivos:** Acceso vía **FTP/SFTP** o mediante el Administrador de Archivos de cPanel/hPanel para subir el código.

## Despliegue 📦

Para asegurar la estabilidad del sistema de la Dulcería Lupita en el hosting:

* Backups Automatizados: Activa los respaldos diarios de la base de datos desde el hosting para prevenir pérdidas de información sobre las ventas y clientes.

* Fuerza HTTPS: Asegúrate de activar la redirección forzada a HTTPS desde el panel para proteger los inicios de sesión de los administradores y los pagos de los clientes de la tienda virtual.

## Construido con 🛠️

El sistema fue desarrollado utilizando tecnologías óptimas para el despliegue en entornos de hosting comercial:

* Node.js & Express - Infraestructura del lado del servidor y construcción de la API REST.

* MySQL - Sistema de gestión de bases de datos relacionales para el control de inventario.

* Tailwind CSS - Framework de estilos para lograr una interfaz moderna y 100% responsiva para tablets y celulares.
